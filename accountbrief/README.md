# AccountBrief AI

**אנליסט אישי וסייען הכנה לפגישות סחר.** בוחרים פגישה ביומן או מקלידים קוד לקוח, והמערכת מכינה תדרוך 360° ללקוח: ביצועים, מוצרים שנעלמו, הזדמנויות ומלאי. מרגע שהתדרוך נפתח, כל שאלה בצ׳אט רצה על הלקוח הזה בלבד.

האפליקציה היא שדרוג של TradeQuery AI. כל השאילתות רצות מקומית בדפדפן על מסד נתונים בזיכרון (AlaSQL), ולכל תשובה יש תובנה, גרף ושאילתת SQL שאפשר לערוך.

## הרצה

```bash
cd accountbrief
python3 -m http.server 8000   # http://localhost:8000
```

אין build ואין backend. AlaSQL,‏ Chart.js ו-SheetJS נטענות מ-CDN בגרסאות נעולות.

## מה חדש

### 1. מודל נתונים ממוקד לקוח
| טבלה | תוכן |
|---|---|
| `customers` | 20 לקוחות (`1001`–`1020`), כל לקוח הוא סניף ברשת: שם, רשת, עיר, מנהל תיק, מסגרת אשראי, יתרה פתוחה, תנאי תשלום, תאריך הזמנה אחרון |
| `sales` | 18,500 שורות חודשיות (אוק׳ 2024 – אוק׳ 2026), כולל `customer_id`, `customer_name`, `account_manager`, `credit_limit`, `last_order_date` |
| `inventory` | תמונת מלאי ל-24/11/2026 לכל לקוח ומוצר, עם אותן עמודות לקוח |

לכל לקוח יש בנתונים מוצרים שננטשו (בלי הזמנות ב-60 הימים האחרונים), מוצרים שהלקוח מעולם לא החזיק (White Space), ירידות חדות והתראות מלאי. ללקוחות של פגישות הדמו נכתבו סיפורים ייעודיים. למשל ל-#1004: מבצע מזון בריאות שרוקן את המדפים, קולה שירדה ב-40%, וחמאת בוטנים שנמכרת בכל הרשת אבל לא אצלו. ל-#1012: ניצול אשראי של 94% ו-57 ימים בלי הזמנה. כל השמות בדויים.

### 2. יומן פגישות
הווידג׳ט „הפגישות הקרובות שלי" נמצא מעל הצ׳אט ותומך בשלוש דרכים לטעינת פגישות:
1. **פגישות דמו** מובנות להיום ולמחר.
2. **ייבוא קובץ `.ics`** (מ-Outlook, Google או Apple), או **הדבקת רשימה** בפורמט כמו `10:30 - פגישת סחר | לקוח 1004`.
3. **Google Calendar API:** התחברות עם OAuth Client ID דרך Google Identity Services (הרשאת `calendar.readonly` בלבד), הדבקת Access Token קיים, או **סימולציה חיה** של סנכרון.

המערכת מזהה את קוד הלקוח מתוך הכותרת, המיקום או התיאור של הפגישה, ולפי ספרות או לפי שם הלקוח. לחיצה על פגישה פותחת את התדרוך. גם חיפוש מהיר בראש המסך (מקש `/`) או הקלדה בצ׳אט („פתח תדרוך ללקוח 1004", או רק `1004`) פותחים אותו.

### 3. תדרוך 360° (Account Brief)
- **כרטיס פרופיל:** שם, קוד, רשת, עיר, מנהל תיק, תנאי תשלום, ניצול מסגרת אשראי (מד צבעוני), הזמנה אחרונה, והפגישה הקרובה.
- **מדדי ליבה:** מכירות מתחילת השנה, צמיחה מול התקופה המקבילה, אחוז רווח גולמי מול ממוצע הרשת, ויתרת מלאי.
- **גרף מגמה:** 12 החודשים האחרונים מול אשתקד.
- **נקודות שיחה מומלצות:** עד 5, מסודרות לפי דחיפות.
- **טבלת נקודות תורפה והזדמנויות:** מוצרים שהופסקו או ירדו (Lost SKUs), White Space, וחוסרים ועודפים במלאי. אפשר לסנן לפי סוג.
- **שקיפות:** כל 9 שאילתות ה-SQL שבנו את התדרוך מוצגות בלשונית נפתחת.

### 4. נעילת הקשר בצ׳אט
כשתדרוך פתוח, מופיעה מעל שורת הכתיבה תגית „מסונן לפי לקוח #1004" עם כפתור לניקוי הסינון. כל שאלה רצה על הלקוח הזה, למשל „מה הרווחיות שלו בקטגוריית הבריאות?" או „הכן לי הצעת מבצע". הצעת המבצע בוחרת מוצרים רווחיים שהמכירות שלהם ירדו מול אשתקד, מציעה מנגנון והנחה לפי אחוז הרווח, ומוסיפה מוצר White Space להשקה.

### 5. דף תדרוך להדפסה
הכפתור „הכן דף תדרוך לפגישה (PDF)" מסדר את הפרופיל, המדדים, הגרף, נקודות השיחה והטבלה בעמוד A4 אחד, דרך חלון ההדפסה של הדפדפן („שמירה כ-PDF").

## מבנה

```
accountbrief/
├── index.html      # שלד: יומן + צ׳אט (35%) | קנבס חי (65%), חלונות ייבוא ו-Google
├── css/styles.css  # שפה עיצובית: שמנת #FAF9F6, משטחים לבנים, אינדיגו / טרקוטה / מרווה
└── js/
    ├── data.js     # מחולל הדאטה-סט: customers / sales / inventory
    ├── engine.js   # NL → SQL, נעילת לקוח, הצעת מבצע, brief(customerId)
    ├── charts.js   # Chart.js, כולל גרף המגמה של התדרוך
    └── app.js      # יומן, ICS, Google, צ׳אט, קנבס, תדרוך, הדפסה, לוח בקרה
```
