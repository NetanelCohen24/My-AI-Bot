# מתכנן הזמנות ותוקף

כלי Web לחברה שמנהלת את המלאי באקסל. מעלים את **אותו קובץ** שעובדים איתו, ומקבלים:
- **מתי כל מוצר ייגמר.** החישוב מתחשב בתוקף של כל אצווה: מלאי שייחסם לפני שיימכר לא נספר.
- **מתי צריך להזמין.** לפי ה-Lead time, מקובץ לפי ספק, עם משטחים ומכולות ליבוא.
- **כמה להזמין.** לפי מכר ומגמה, עם תקרה לפי חיי מדף כדי לא להזמין יותר ממה שיספיק להימכר.
- **סכנת תוקף.** אילו אצוות לא יספיקו להימכר לפני מועד החסימה, ומה ההמלצה (מבצע או תרומה).

העיבוד מתבצע בדפדפן בלבד, והקובץ לא נשלח לשום שרת.

## הרצה
```bash
cd order-planner && npm install
npm run dev    # http://localhost:5173
npm test
```

## מה נקרא מהקובץ
הגיליונות מזוהים לפי הכותרות שלהם ולא לפי השם:

| גיליון | עמודות שמזוהות |
|---|---|
| מלאי לפי אצוות (למשל "מאסטר מלאי מול תוקף") | חומר, תיאור חומר, תאריך פג תוקף, בלתי-מוגבל, יח' בתיבה, ספק, יצור מקומי/יבוא, lead time, כמות מינימום, ימים לחסימה, מותג, ABC |
| מכר חודשי (כל הגיליונות מהסוג הזה מאוחדים) | מק"ט/חומר ועמודה לכל חודש (Jan-25, 01/2025 וכו') |
| זמני אספקה ויצרן | lead time, כמות תיבות במשטח, מחירון, חיי מדף בימים, מינימום |

- **סדר האצוות:** אין צורך למיין אותן לפי תוקף. המערכת ממיינת בעצמה.
- **חודשים עתידיים ריקים:** חודשים שממולאים ב-"-" (אפס) מזוהים כחודשים שעוד לא קרו.

## אופן החישוב
- **צפי מכר.** ממוצע משוקלל של 3 החודשים האחרונים (3:2:1). אפשר לבחור במקומו ממוצע של 12 חודשים או את עמודת הממוצע מהקובץ. למכר הרגיל מתווספים מבצעים שמזינים במסך.
- **סימולציה יומית לפי FEFO.** האצווה שתפוגתה קרובה יותר נמכרת ראשונה. אצווה נחסמת N ימים לפני תום התוקף, ומה שנשאר בה באותו יום נחשב "סכנת תוקף".
- **להזמין עד.** היום שבו המלאי השמיש יורד מתחת למלאי הביטחון, פחות ה-Lead time. מלאי הביטחון הוא הגבוה מבין המינימום שהוגדר למוצר לבין 14 ימי מכר.
- **סטטוסים.**
  - **אזל:** אין עכשיו מלאי שמיש.
  - **יחסר:** המוצר ייגמר לפני שהזמנה שתבוצע היום תספיק להגיע.
  - **להזמין עכשיו:** מועד ההזמנה כבר עבר.
  - **להזמין בקרוב:** מועד ההזמנה ב-21 הימים הקרובים.
- **כמות מוצעת.**
  - מכסה 1.5 חודשים (ספק מקומי) או 3 חודשים (יבוא) אחרי ההגעה, ועוד מלאי הביטחון.
  - מוגבלת למה שאפשר למכור לפני מועד החסימה, בהנחה שהסחורה מגיעה עם 85% מחיי המדף שלה.
  - ביבוא מעוגלת למשטחים מלאים.
