# TradeQuery AI

**אנליסט וירטואלי לתשאול נתוני מכירות ומלאי בשפה טבעית (עברית + אנגלית).**
כל שאלה מתורגמת ל-SQL, רצה מקומית בדפדפן על מסד נתונים בזיכרון (AlaSQL), ומחזירה שלוש שכבות שקופות:

1. **תובנה עסקית** — כותרת וסיכום קצר בעברית.
2. **ויזואליזציה דינמית** — נבחרת אוטומטית לפי סוג השאלה (עמודות להשוואה, קו למגמה, טבעת לנתח, טבלה לפירוט, כרטיסי KPI לסיכום), עם אפשרות להחליף ידנית.
3. **שאילתת ה-SQL המדויקת** — בלשונית נפתחת, עם אפשרות לערוך ולהריץ מחדש (Ctrl/⌘+Enter). הגרף והתובנה מתעדכנים לפי התוצאה.

אחרי כל תשובה מוצעות 3 **שאלות המשך** להעמקה (drill-down), וכפתור **„הצמד ללוח הבקרה"** אוסף גרפים מתשובות שונות לדף סיכום אחד שאפשר להדפיס או לשמור כ-PDF.

## הרצה

האפליקציה סטטית לגמרי, בלי build ובלי שרת backend:

```bash
cd tradequery
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

הספריות (AlaSQL, Chart.js ו-SheetJS) נטענות מ-CDN בגרסאות נעולות.

## הדאטה-סט המובנה

נתוני FMCG סינתטיים ודטרמיניסטיים (`js/data.js`). כל הרשתות, המותגים והסניפים **בדויים**:

| טבלה | תוכן |
|---|---|
| `sales` | 19,200 שורות: חודש × סניף × מוצר, אוקטובר 2024 – ספטמבר 2026. 5 רשתות, 20 סניפים ב-11 ערים, 8 קטגוריות, 40 מוצרים, סגמנט בריאות/רגיל, יחידות, הכנסות, עלות מכר, רווח גולמי |
| `inventory` | 800 שורות: תמונת מלאי ל-30/09/2026, ימי מלאי, שווי מלאי, סטטוס (חוסר צפוי / תקין / עודף) |

בנתונים שתולים „סיפורים" עסקיים שהמערכת אמורה לגלות, למשל מבצע מזון בריאות ב„סופר גל" ב-Q3 2026, תקלת מקררים ב„אורן מרקט", צמיחה מהירה של מוצרי בריאות ב„פרש פוינט", ושחיקת רווחיות ברשת הדיסקאונט.

## מנוע ה-NLQ (`js/engine.js`)

מפענח סמנטי מקומי ודטרמיניסטי. אין קריאה ל-LLM ושום נתון לא יוצא מהדפדפן:

- **ישויות**: זיהוי ערכים מהנתונים (רשתות, קטגוריות, ערים, סניפים, מוצרים ומותגים, כולל כינויים באנגלית), עם תמיכה בתחיליות עבריות (ב/ה/ל/מ/ש/ו/כ).
- **מדדים**: הכנסות, יחידות, רווח גולמי, אחוז רווח גולמי, עלות מכר, מחיר ממוצע, ומדדי מלאי.
- **חיתוכים**: רשת / קטגוריה / סניף / עיר / מוצר / מותג / סגמנט / חודש / רבעון, עד שני חיתוכים במקביל.
- **זמן**: רבעון אחרון, `Q2 2026`, „רבעון שני", שנה, „השנה", חודש בשם, „6 החודשים האחרונים", „לעומת אשתקד" (YoY).
- **כוונות**: צמיחה, מגמה, נתח, דירוג (גבוה/נמוך, Top N), סיכום, בריאות מול רגיל, מלאי (חוסרים / עודפים / סקירה).
- **שאלות המשך בהקשר**: למשל „ומה לגבי פרש פוינט?" ממשיכה את השאלה הקודמת ומעמיקה רמה אחת.

## העלאת קבצים

כפתור „העלאת קובץ" (או גרירה לחלון) מקבל CSV או Excel:
- קובץ במבנה טבלת `sales` מחליף את הדאטה-סט ונהנה מהמנוע הסמנטי המלא.
- כל קובץ אחר נטען לטבלה `uploaded`. המערכת מזהה עמודות מספריות, טקסט ותאריכים, ומאפשרת שאלות כמו „מה הסכום לפי אזור?" או „מה המגמה החודשית של סכום באזור צפון?".
