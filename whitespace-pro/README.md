# WhiteSpace Pro

אפליקציית Web לזיהוי פערי הפצה והזדמנויות Cross-Sell / Assortment Gaps בנקודות מכירה קמעונאיות.

## הפעלה
קובץ יחיד, ללא שלב build: פותחים את `index.html` בדפדפן (או `python3 -m http.server` מתוך התיקייה).
האפליקציה נטענת עם נתוני הדגמה (רשתות ומוצרים בדויים). כפתור "טעינת CSV" מריץ את המנוע על נתונים אמיתיים.

## פורמט CSV
שורה לכל סניף × מוצר, חודש מכירות אחד:

```
chain,store,region,size_sqm,category,family,sku,is_hero,price,units
```

* `is_hero` – 1 למוצר הליבה של המשפחה (אם חסר, המוצר הנמכר ביותר במשפחה נבחר אוטומטית).
* מוצר שאינו במגוון הסניף פשוט לא מופיע. מוצר רשום ללא מכירות מופיע עם `units=0`.
* `region` – צפון, חיפה והקריות, שרון, מרכז, ירושלים, שפלה, דרום (משמש לציר הגיאוגרפי באשכול).

## White Space Engine
1. **אשכול סניפים דומים** – k-means (k≈√(n/2)) על גודל סניף (לוג), היקף מכירות (לוג) ומיקום צפון→דרום.
2. **Hero חזק** – אחוזון ה-Hero בתוך קבוצת הדומים מעל סף (ברירת מחדל P75, ניתן לשינוי).
3. **פער** – מוצר משלים מאותה משפחה שחסר במגוון או נמכר ב-0 יחידות.
4. **Revenue Uplift** – ממוצע יחידות אצל סניפים דומים באותה רשת שמוכרים את המוצר (לפחות 3, אחרת כל הקבוצה) × יחס היקף מכירות (0.75–1.25) × מחיר.
5. **ציון 0–100** – 45% דירוג שווי, 35% אחוזון Hero, 20% שיעור פיזור אצל הדומים.

סטטוסי טיפול ויעדי סוכן נשמרים ב-localStorage של הדפדפן.
